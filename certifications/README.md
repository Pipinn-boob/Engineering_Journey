# Certifications Roadmap

Order chosen for a student budget: everything free first, then the cheapest
certificate with real local demand (MTCNA), then CCNA. Prices are
approximate and change — always confirm on the official page before booking.

| # | Certification | Provider | Approx. cost | Status | Target |
| - | ------------- | -------- | ------------ | ------ | ------ |
| 1 | Networking Basics | Cisco Networking Academy | Free | Planned | Dec 2026 |

| 7 | AWS Cloud Practitioner | AWS | ~USD 100 | Optional | after CCNA |
| 8 | PCEP (Certified Entry-Level Python Programmer) | Python Institute | ~USD 60 | Optional | dev-track only |

## Why this order

- The NetAcad courses are free, aligned with my degree, and issue
  verifiable digital badges — HR filters often look for certificates before
  anyone reads the projects.
- Kenyan ISPs and WISPs run a lot of MikroTik equipment, so MTCNA is the
  cheapest paid certificate with genuine local demand.
- CCNA is the recognized bar for network roles; the
  [networking notes](../networking_basics/README.md) are already structured
  around its topics.
